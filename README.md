# EquilíbrioLab — Protótipo de Avaliação Postural Inercial

Protótipo web funcional para avaliação de oscilações do equilíbrio postural utilizando acelerômetro e giroscópio (IMU) de smartphone.

- Demonstração online via GitHub Pages: [https://matheusmaiadev.github.io/equilibriolab-demo/](https://matheusmaiadev.github.io/equilibriolab-demo/)
- Produto técnico voltado para TCC de Residência.
